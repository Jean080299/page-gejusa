# Requerimientos del Proyecto - Micro Habit Tracker

## Requerimientos funcionales
1. Registro e inicio de sesión de usuarios.
2. Creación de hábitos y metas personales.
3. Panel principal de seguimiento de hábitos.
4. Organización de metas por categorías.
5. Seguimiento y análisis del progreso.
6. Visualización de estadísticas de hábitos.
7. Motivación y contenido adicional para usuarios.
8. Compartir reflexiones o avances.
9. Interfaz responsiva para dispositivos móviles y escritorio.
10. Navegación entre pantallas del sistema.

## Requerimientos no funcionales
1. Interfaz amigable y moderna.
2. Diseño adaptable (responsive design).
3. Compatibilidad con navegadores modernos.
4. Tiempo de carga rápido.
5. Código HTML estructurado y mantenible.
6. Uso de TailwindCSS para estilos.
7. Accesibilidad básica en navegación y formularios.

## Tecnologías utilizadas
- HTML5
- TailwindCSS
- Google Fonts
- Material Symbols Icons

## Estructura sugerida para GitHub Pages
- index.html
- carpetas individuales para cada pantalla
- recursos visuales (screen.png)

## Recomendaciones
- Convertir posteriormente a React o Next.js si se desea funcionalidad dinámica.
- Agregar backend para autenticación y almacenamiento real.
